# AI 游戏开发学习反馈

这里收集轨道课堂的网站问题、资料纠错、视频失效和学习建议。

## 学生提交

1. 在学习网站填写自己的姓名；这是展示名，不是身份认证。
2. 点击“问题反馈”，写明具体情况、复现步骤和期望结果。
3. 网站打开预填好的 GitHub Issue 页面，使用你自己的 GitHub 账号登录，再点击提交。
4. 也可直接在本仓库 Issues → New issue 使用学生反馈表单。

**本仓库公开。姓名、文字和附件对所有人可见。请勿提交密码、令牌、联系方式或他人隐私。**
没有 GitHub 账号时可复制问题描述，通过与老师约定的渠道发送；保存草稿或打开填写页不代表老师已收到。

## 老师处理

- 按姓名、站点和分类搜索；GitHub账号和自填姓名一起帮助核对提交者。
- 先复现，使用“待处理 / 处理中 / 已修复 / 待补充”标记状态。
- 修复后在 Issue 中说明更新内容与验证结果，再关闭问题。
- 学习存档保存在学生浏览器；此仓库不自动收集整份学习数据。
- 网站实践证据属于待教师确认，本仓库不是自动评分后台。
